코드 서명 정책

IngeTrazo의 Windows 프로그램이 어떻게 서명되고, 누가 책임지는지 설명합니다.

SignPath.io의 무료 코드 서명, SignPath Foundation의 인증서.

현황: SignPath를 통한 서명을 준비하고 있습니다. 준비가 끝날 때까지 Windows 프로그램은 서명 없이 배포되며, 이 페이지는 앞으로 서명할 방식을 설명하고 서명이 시작되면 업데이트됩니다.

서명 대상

  • IngeTrazo의 Windows 실행 파일 ingetrazo.exe, ingetrazo-mcp.exe와 설치 프로그램 ingetrazo-setup-<버전>.exe.
  • 이 프로젝트의 공개 소스 코드로 빌드한 것만 서명합니다. 패키지에 함께 들어 있는 제3자 구성 요소(Python, Qt/PySide6 및 기타 자유 라이브러리)는 우리 인증서로 서명하지 않습니다.
  • 모든 릴리스는 공개 저장소에서 "Build Windows" 워크플로로 GitHub Actions에서 빌드됩니다. 배포되는 어떤 것도 개인 컴퓨터에서 빌드하지 않습니다. 다운로드는 GitHub 릴리스 페이지에 있습니다.

팀 역할

  • 커미터와 리뷰어: 코드는 프로젝트 메인테이너와 기여자가 작성합니다. 기여자의 모든 변경은 공개 풀 리퀘스트로 들어오며, 메인테이너가 검토한 뒤 받아들입니다.
  • 승인자: 프로젝트 메인테이너 Marco Sumari Tellez(@tuxiasumari). 모든 릴리스 서명은 수동으로 승인합니다.
  • 저장소와 서명에 접근할 수 있는 계정은 2단계 인증을 사용합니다.

개인정보 처리방침

이 프로그램은 사용자 또는 프로그램을 설치·운영하는 사람이 명시적으로 요청하지 않는 한, 어떤 정보도 네트워크상의 다른 시스템으로 전송하지 않습니다. 원격 측정(텔레메트리)이 없으며 스스로 업데이트를 확인하지도 않습니다. 인터넷이 필요한 기능을 사용할 때만 연결합니다:

  • 지도·지형 타일(OpenStreetMap, Esri, EOX, Sentinel-2, AWS Open Data의 표고 모델)과 장소 검색(Nominatim).
  • IP 주소로 도시를 추정하는 "내 위치" 버튼(ipapi.co).
  • 컴포넌트 라이브러리(ingetrazo.com)와 재질·모델 라이브러리(Poly Haven, ambientCG, Sketchfab).
  • AI 어시스턴트. 사용자가 직접 고르고 자신의 키로 설정한 제공업체(또는 Ollama 같은 로컬 모델)와만 통신합니다.

파일 확인 방법

  • Windows에서: .exe를 마우스 오른쪽 버튼으로 클릭 ▸ 속성 ▸ 디지털 서명 탭.
  • 백신 프로그램이 IngeTrazo 파일을 위험하다고 표시하면 GitHub이나 이메일로 알려 주세요.
