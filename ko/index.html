모델링, 분류, 도면화에 필요한 모든 것

손으로 그리듯이

선, 사각형, 원, 호를 그리고 면을 밀면 솔리드가 됩니다. 아이디어와 모델 사이에 복잡한 CAD 단계가 끼어들지 않습니다.

  • 밀기/끌기, 경로 따라가기, 간격 띄우기 — 메뉴에 가로막히지 않고 면을 밀어 모델링합니다
  • 키보드로 정확한 치수 입력 — 3.50을 입력하면 선의 길이가 3.50 m가 됩니다
  • 스마트 추론 — 축, 연장선, 평행선, 수직선
  • 어떤 면에든 재질, 텍스처, 치수

한 걸음씩 나아가는 BIM

지금 만들고 있는 선택형 레이어입니다. 자유롭게 모델링하다가 필요할 때 형상을 벽, 슬래브, 기둥, 문으로 분류합니다.

  • BIM 태그 — 이미 그린 것에 벽, 슬래브, 기둥, 문을 표시합니다
  • 물량 — 분류된 요소의 벽 m²와 기둥 m³를 CSV 표로
  • IFC 4 내보내기 — 모델을 다른 프로그램으로 가져가는 오픈 파일
  • 개발 중 — 버전마다 늘어납니다. 필요한 기능을 GitHub에 알려 주세요

수밀(닫힌) 솔리드 보장: 어떤 작업이 볼륨을 깨뜨리려 하면 엔진이 물량 산출을 망가뜨리는 대신 그 작업을 거부합니다.

모든 것은 지형에서 시작합니다

위성 이미지, 3D 지형, 현장 데이터로 프로젝트를 실제 세계에 배치합니다. 모델러 안에서 바로.

  • 위성 이미지를 입힌 3D 지형 — 현장의 실제 표고
  • 종단면도 — 노선을 그리면 바로 종단면을 볼 수 있습니다
  • 드론 측량(WebODM) — 텍스처가 입혀진 사진측량 메시를 실제 표고와 함께 참조로 사용
  • GPS / 토털 스테이션 점 — UTM 좌표 CSV를 가져와 정확한 점 위에 그립니다
  • 인터페이스 전체에서 UTM WGS84 — 측량 장비가 알려 주는 그대로 존/E/N을 입력합니다
  • 프로젝트 북 — 축에 맞춰 반듯하게 그리면 지도, 지형, 그림자가 아래에서 회전합니다
  • 측점과 면적이 있는 지리 참조 노선과 경계

모델러 전체가 오프라인으로 동작하며, 지도만 인터넷을 사용합니다.

모델에서 출력 도면까지

QGIS처럼 시트를 구성합니다: 모델의 뷰를 정확한 축척으로 시트에 배치하고, 치수는 스스로 다시 재며, 설계 도서에 바로 쓸 벡터 PDF로 내보냅니다.

  • 보장되는 실제 축척 — 200 mm 프레임 안의 1:100은 언제나 모델의 20 m입니다
  • 모델에 연결된 치수 — 벽을 고치면 치수가 따라 움직이며 다시 잽니다. 합계가 표시되는 연속 치수, 점의 높이를 읽는 레벨 표시
  • 정확한 벡터 은선 스타일 — 세 가지 펜(절단, 윤곽, 모서리)과 단면의 해치(poché): 제도사가 잉크로 그릴 도면 그대로
  • 번호가 붙은 뷰 제목, 단면 표시, 상세 콜아웃 — 평면도에 A-A 단면이 어디를 자르는지, 각 상세가 어느 시트에서 확대되는지 표시됩니다
  • 편집 가능한 표제란, 그래픽 축척, 방위 표시 — 문서 하나에 여러 시트, 클릭 한 번으로 PDF
  • IngeCAD로 DXF — 선 종류마다 레이어 하나씩 나뉜 벡터 뷰. 같은 생태계의 무료 CAD에서 2D 상세를 마무리하세요

그리고 더 있습니다

AI로 모델링 — 앱 안에서, 또는 Claude에서

원하는 것을 설명하거나 사진을 첨부하면 AI가 레시피를 작성합니다: 회전체, 돌출, IngeTrazo 액션 API 위의 Python. 결정론적 엔진이 이를 실행합니다. 각 단계는 실행 취소 한 번이고, 모든 레시피는 수밀성 검사를 거치며, 모델은 여전히 여러분의 것으로 손으로 편집할 수 있습니다.

  • 내장 AI 어시스턴트(사이드바의 AI 탭, Ctrl+Shift+A) — 내 키로 쓰는 채팅: Groq(무료 등급 있음), Gemini, OpenAI, Anthropic, OpenRouter, DeepSeek 또는 Ollama 로컬 모델. 중개자 없음
  • 자기가 한 일을 봅니다 — 뷰포트 스크린샷을 받아 보고 고칩니다. Photo…로 이미지 속 대상을 여러분이 준 치수에 맞춰 다시 만듭니다
  • Claude Desktop과 Claude Code용 MCP 브리지 — 에이전트가 열려 있는 앱에서 실시간으로 모델을 그리고, 조회하고, 봅니다. 동작마다 실행 취소 한 단계이며, 코드가 실패하면 문서는 그대로 돌아옵니다

장면을 채우느라 오후를 다 쓰지 마세요

모델은 옆에 사람과 나무, 자동차가 있어야 실감이 납니다. IngeTrazo는 클릭 한 번 거리에 컴포넌트 1,510개와 텍스처 427개를 제공하며, 모두 아무 크기가 아니라 실제 크기로 들어옵니다.

  • 온라인 모델 1,510개 — 가구, 문, 창, 나무, 차량, 사람. 둘러보는 데는 킬로바이트 수준이며, 클릭한 것만 내려받아 보관합니다
  • 오프라인에서도 — 모델 8개와 축척 인물 6개가 프로그램에 들어 있습니다
  • 실제 크기의 텍스처 427개 — 벽돌이 벽돌처럼 보이는 건 눈대중이 아니라 카탈로그가 크기를 알려 주기 때문입니다

모든 콘텐츠는 자유 라이브러리인 Sweet Home 3D(CC0, CC BY, Free Art License)에서 왔으며, IngeTrazo는 항상 각 항목의 라이선스와 작성자를 표시합니다.

기존 도면과 모델을 그대로

오랜 세월 쌓은 라이브러리도, 동료들도 남겨 두지 않습니다. IngeTrazo는 DWG와 DXF 도면, 오픈 리더 OpenSKP 덕분에 모든 버전의 .skp 모델, 그리고 OBJ, COLLADA, glTF, STL을 가져옵니다. 변환기도, 추가 설치도 필요 없습니다.

  • DWG와 DXF 도면 — 레이어마다 그룹 하나로, 바로 따라 그리고 쌓아 올릴 수 있게
  • 안에 있는 모든 것과 함께 — 그룹, 컴포넌트, 재질, 텍스처, 레이어, 장면, 치수, 지시선 텍스트
  • 모델을 다시 가져가려면 — 거의 모든 3D 프로그램이 여는 COLLADA(.dae), glTF, OBJ로 내보내기
  • 그 밖에 OBJ, COLLADA, glTF, STL과 IFC

설치 방법 ▾

저장소에서 설치하면 flatpak update로 새 버전을 모두 받을 수 있습니다. 응용 프로그램 메뉴에 나타나며 .igz와 .skp 파일이 연결됩니다.

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo flatpak remote-add --user --if-not-exists ingetrazo https://ingetrazo.com/ingetrazo.flatpakrepo flatpak install --user ingetrazo com.ingetrazo.IngeTrazo flatpak run com.ingetrazo.IngeTrazo

단독 파일이 좋으신가요? 위 카드로 내려받아 더블클릭하면 설치되지만, 그 방식은 스스로 업데이트되지 않습니다.

아무것도 설치하지 않습니다: 실행 권한을 주고 여세요(또는 파일 관리자에서 더블클릭).

chmod +x IngeTrazo-0.5.10-x86_64.AppImage ./IngeTrazo-0.5.10-x86_64.AppImage

FUSE가 필요하며, 거의 모든 배포판에 들어 있습니다. 없다면 tar.gz를 사용하세요.

FUSE가 없는 배포판이나 /opt 아래에 설치하려는 경우: 압축을 풀고 실행하세요.

tar -xzf IngeTrazo-0.5.10-linux-x86_64.tar.gz IngeTrazo-0.5.10/ingetrazo

AppImage와 내용이 같습니다: Python, Qt, .skp 리더가 함께 들어 있습니다.

세 가지 모두 Ubuntu 22.04 이상에서 동작합니다. 문제가 있으면 --check 옵션으로 실행하면 무엇이 빠졌는지 알려 줍니다(예: flatpak run com.ingetrazo.IngeTrazo --check 또는 ./IngeTrazo-*-x86_64.AppImage --check).

소스에서 실행할 수도 있습니다(명령 3개, README 참고). 모든 파일은 GitHub 릴리스에 있습니다.

.dmg를 열고 IngeTrazo를 응용 프로그램 폴더로 끌어 놓으세요. 아직 Apple 계정으로 서명되지 않았기 때문에 처음 한 번은 더블클릭으로 열리지 않고 개발자를 확인할 수 없다는 메시지가 나옵니다. 아래 방법으로 한 번만 허용하면 됩니다. 그 뒤로는 평소처럼 열리고, .igz와 .skp 파일도 더블클릭으로 열립니다. 패키징: Félix Riestra.

macOS에서 IngeTrazo가 열리지 않을 때: 허용하는 방법

macOS 15 Sequoia 이상(마우스 오른쪽 클릭만으로는 더 이상 안 됨):

  1. IngeTrazo를 열어 보고 경고 창에서 완료를 누릅니다.
  2. Apple 메뉴 ▸ 시스템 설정 ▸ 개인정보 보호 및 보안을 엽니다.
  3. 아래쪽 보안 항목에 IngeTrazo가 차단되었다고 나옵니다. 그래도 열기를 누르고 Touch ID나 암호로 확인합니다.

macOS 14 이하: 응용 프로그램 폴더에서 IngeTrazo를 마우스 오른쪽 버튼으로 클릭(또는 Control-클릭) ▸ 열기를 선택하고, 경고 창에서 다시 열기를 누릅니다.

그래도 열리지 않으면 터미널에서 "인터넷에서 다운로드됨" 표시를 지우고 다시 여세요:

xattr -dr com.apple.quarantine /Applications/IngeTrazo.app

신뢰하는 소프트웨어에만 이렇게 하세요. 이 페이지의 프로그램은 GitHub에 공개된 코드와 같습니다. 커뮤니티가 토론 #324에서 기여한 가이드입니다.

내 Mac에 맞는 것을 고르세요: Apple 메뉴 ▸ 이 Mac에 관하여에서 «칩 Apple M…»이면 Apple Silicon, «프로세서 Intel»이면 Intel입니다. Mac에서 아직 안 되는 것: DWG 가져오기(.skp 열기는 됩니다). 문제가 있으면 GitHub 이슈로 알려 주세요.

자주 묻는 질문

첫 선을 긋기 전에 다들 묻는 것들.

여기서 말하는 오픈소스란 무엇인가요?

IngeTrazo는 GPL-3.0 오픈소스 소프트웨어입니다. 어떤 프로젝트에든 사용하고, 작동 방식을 연구하고, 개선하고, 공유할 수 있으며 소스 코드는 GitHub에 공개되어 있습니다. 여러분의 모델은 여러분의 것입니다.

IngeTrazo는 무엇이 다른가요?

오픈소스 소프트웨어(GPL-3.0)이며 Windows, macOS뿐 아니라 Linux에서도 네이티브로 동작합니다. 수밀(닫힌) 솔리드를 보장하고, 개발 중인 선택형 BIM 레이어를 제공합니다. 축척에 맞춘 시트를 PDF로 구성하고, 실제 지형(위성, 표고, 드론, GPS 점)을 불러오며, 같은 엔진으로 그리는 AI 어시스턴트와 연결됩니다. 모든 단계는 실행 취소할 수 있습니다.

어떤 형식을 열고 저장하나요?

자체 형식인 .igz 문서, DWG와 DXF 도면, 모든 버전의 .skp 모델(IngeTrazo가 기여하는 오픈 리더 OpenSKP 사용), COLLADA(.dae), OBJ, glTF, STL을 엽니다. 오픈 형식인 .igz로 저장하고, COLLADA, OBJ, glTF, STL, IFC, DXF, PDF 도면으로 내보냅니다.

BIM을 지원하나요?

개발 중인 선택형 레이어로 지원합니다. 형상을 벽, 슬래브, 기둥, 문으로 분류하고, 물량(m², m³, 개수)을 구하고, 다른 프로그램(IngePresupuestos 포함)이 읽는 표준 형식인 IFC로 내보낼 수 있습니다. 버전마다 기능이 늘어납니다.

프로젝트 도면을 만들 수 있나요?

네. 시트 구성기는 모델의 뷰를 A4–A0 시트에 정확한 축척(1:50, 1:100…)으로 배치합니다. 모델에 연결되어 모델이 바뀌면 함께 갱신되는 치수, 편집 가능한 표제란, 그래픽 축척, 번호가 붙은 뷰 제목, 단면 표시, 레벨 표시와 연속 치수, 상세 콜아웃, 펜과 단면 해치(poché)를 갖춘 벡터 은선 스타일을 제공합니다. 각 시트 또는 전체 세트를 벡터 PDF로, 뷰를 DXF로 내보낼 수 있습니다.

플러그인으로 기능을 추가할 수 있나요?

네. 버전 0.3.2부터 IngeTrazo에는 Extensions 메뉴가 있습니다. 플러그인(Python 파일)을 개인 폴더에 복사하면 해당 도구가 메뉴에 나타납니다. 두 가지가 기본 포함되어 있습니다: Model Info(통계, 칠해진 m²가 표시되는 재질, BIM 객체)와 코드로 모델을 살펴보고 자동화하는 Python Console이며, 모두 실행 취소와 연동됩니다. 가이드는 매뉴얼(스페인어)에 있습니다.

인공지능 기능이 있나요?

네, 두 가지 방식이 있습니다. 내장 AI 어시스턴트는 채팅입니다. 원하는 제공업체의 키를 붙여 넣고(Groq는 무료 등급이 있고, Gemini, OpenAI, Anthropic, OpenRouter, DeepSeek 또는 내 컴퓨터의 Ollama도 가능) 말이나 사진으로 모델을 설명하면 됩니다. 그리고 MCP 브리지를 통해 Claude Desktop이나 Claude Code가 열려 있는 앱에 직접 그릴 수 있습니다. 두 경우 모두 AI는 엔진이 실행하는 레시피를 만들고 —맹목적인 메시는 절대 아닙니다—, 모든 단계는 실행 취소할 수 있으며, 모델은 손으로 계속 편집할 수 있습니다. AI 없이도 IngeTrazo는 똑같이, 오프라인으로 동작합니다.

오프라인에서도 동작하나요?

네, 모델러 전체가 오프라인으로 동작하며 파일은 여러분의 컴퓨터에 저장됩니다. 위성 지도와 3D 지형만 사용하는 동안 인터넷에서 이미지를 내려받습니다.

어떻게 설치하나요?

Windows: 다운로드 섹션에서 설치 프로그램을 내려받아 더블클릭하면 끝입니다(.igz 파일이 연결됨). Linux: Flatpak(더블클릭하면 GNOME 소프트웨어 / KDE Discover가 설치하며 .igz와 .skp 파일이 연결됨), AppImage(실행 권한을 주고 열기) 또는 배포판에 FUSE가 없다면 tar.gz를 내려받아 아무 곳에나 압축을 풀고 ingetrazo를 실행합니다. 동작하지 않으면 --check가 무엇이 빠졌는지 알려 줍니다. macOS(Apple Silicon): 다운로드 ▸ macOS에서 .dmg를 내려받아 IngeTrazo를 응용 프로그램으로 끌어 놓고, 아직 Apple 계정으로 서명되지 않았으므로 처음 한 번은 시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 그래도 열기로 허용합니다(macOS 14 이하는 마우스 오른쪽 클릭 ▸ 열기). 명령 3개로 소스에서 실행할 수도 있습니다.

3D 프린팅에 적합한가요?

아직 강점은 아니지만 계획에 있습니다. 지금도 바이너리 STL로 내보내 슬라이서에서 사용할 수 있고, 엔진이 만드는 솔리드는 닫혀 있습니다. 아직 없는 것은 3D 프린팅 전용 도구(벽 두께 검사, 오버행, 메시 복구, 3MF)이며, 앞으로 추가할 예정입니다.

문제를 보고하거나 기여하려면 어떻게 하나요?

프로젝트는 GitHub에 있습니다. 예제 파일과 함께 이슈를 열거나, 개선을 제안하거나, 코드를 보내 주세요. 이메일로 연락하셔도 됩니다.
