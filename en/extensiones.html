How to install

  1. In IngeTrazo open Extensions ▸ Manage extensions… (since version 0.5.8).
  2. In the Browse tab find the extension and click Install. IngeTrazo downloads it, checks it is exactly the approved file and turns it on.
  3. For a community extension, IngeTrazo asks you before installing it. The ones you have are in the Installed tab.

Offline, or on an older version? Click Download, unzip the .zip, copy the whole folder into Extensions ▸ Open extensions folder and reopen IngeTrazo.

Reviewed and community

Reviewed a maintainer of IngeTrazo read the code of that exact version.

Community passed the automatic check, but nobody read the code in depth. Install it if you trust its author.

An extension is a program with the same access to your computer as IngeTrazo, as in Blender. The Download button checks the file is exactly the one that was approved.
