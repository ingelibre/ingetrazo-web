How to install

  1. Click Download on the extension.
  2. In IngeTrazo open Extensions ▸ Open plugins folder and copy the file there.
  3. Restart IngeTrazo. The extension shows up in the Extensions menu or in the side panel.

Soon you will install them from inside IngeTrazo with one click.

Reviewed and community

Reviewed a maintainer of IngeTrazo read the code of that exact version.

Community passed the automatic check, but nobody read the code in depth. Install it if you trust its author.

An extension is a program with the same access to your computer as IngeTrazo, as in Blender. The Download button checks the file is exactly the one that was approved.
