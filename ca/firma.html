Política de signatura de codi

Com se signen els programes d'IngeTrazo per a Windows i qui en respon.

Signatura de codi gratuïta proporcionada per SignPath.io, certificat de SignPath Foundation.

Estat: l'alta de la signatura amb SignPath està en tràmit. Fins que no s'hagi completat, els programes per a Windows es publiquen sense signar; aquesta pàgina explica com se signaran i s'actualitzarà quan es comenci.

Què se signa

  • Els executables d'IngeTrazo per a Windows: ingetrazo.exe i ingetrazo-mcp.exe, i l'instal·lador ingetrazo-setup-<versió>.exe.
  • Només se signa el que es compila a partir del codi font públic d'aquest projecte. Els components de tercers que van dins del paquet (Python, Qt/PySide6 i altres biblioteques lliures) no se signen amb el nostre certificat.
  • Cada versió es compila a GitHub Actions, a partir del repositori públic, amb el flux de treball «Build Windows»; ningú no compila al seu propi ordinador el que es publica. Les descàrregues són a les versions publicades a GitHub.

Rols de l'equip

  • Autoria i revisió: el codi l'escriuen la persona responsable del projecte i les persones col·laboradores. Tot canvi d'una persona col·laboradora entra amb una pull request pública que la persona responsable revisa abans d'acceptar-la.
  • Aprovació: Marco Sumari Tellez (@tuxiasumari), responsable del projecte. Cada signatura d'una versió s'aprova a mà.
  • Els comptes amb accés al repositori i a la signatura fan servir autenticació en dos passos.

Privacitat

Aquest programa no transfereix cap informació a altres sistemes en xarxa si no ho demana expressament l'usuari o la persona que l'instal·la o el fa servir. No té telemetria ni busca actualitzacions pel seu compte. Només es connecta quan fas servir una funció que ho necessita:

  • Mapes i relleu del terreny (OpenStreetMap, Esri, EOX, Sentinel-2, models d'elevació d'AWS Open Data) i la cerca de llocs (Nominatim).
  • El botó «Ubica'm», que estima la teva ciutat a partir de la teva adreça IP (ipapi.co).
  • La biblioteca de components (ingetrazo.com) i la de materials i models (Poly Haven, ambientCG, Sketchfab).
  • L'assistent d'IA, que només parla amb el proveïdor que triïs i configuris amb la teva pròpia clau (o amb un model local, com Ollama).

Com es comprova un fitxer

  • A Windows: clic dret sobre el .exe ▸ Propietats ▸ pestanya Signatures digitals.
  • Si un antivirus marca un fitxer d'IngeTrazo, avisa'ns a GitHub o per correu.
